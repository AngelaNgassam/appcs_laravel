Format du fichier Excel

Votre fichier doit contenir les colonnes suivantes (dans cet ordre) :

  1. Matricule (obligatoire, unique)
  2. Nom (obligatoire)
  3. Prénom (obligatoire)
  4. Date de naissance Format accepté : JJ/MM/AAAA
    Exemples : 05/11/2011, 20/08/2010
  5. Sexe (M ou F)
  6. Lieu de naissance (optionnel)
  7. Contact parent (optionnel)
  8. Nom parent (optionnel)
Important : Les dates doivent être au format JJ/MM/AAAA (ex: 05/11/2011)
